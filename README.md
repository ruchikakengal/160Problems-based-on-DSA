# 📘 160 Problems Based on DSA

This repository contains **160 Data Structures and Algorithms (DSA) problems** with solutions.  
The goal of this project is to help learners and developers strengthen their **problem-solving skills** and build a solid foundation in **DSA concepts**.

---

## 🚀 Features
- Covers **160 problems** from beginner to advanced level.
- Solutions written in **Python 3** (primary) and **Java** (for contests).
- Organized by **topics** for easier navigation.
- Clean and structured code (no extra comments, only logic).
- Useful for **coding interviews, competitive programming, and placements**.

---

## 🗂️ Problem Categories
The problems are divided into various DSA topics:
- Arrays
- Strings
- Recursion & Backtracking
- Searching & Sorting
- Linked List
- Stack & Queue
- Trees
- Graphs
- Dynamic Programming
- Greedy Algorithms
- Divide & Conquer
- Tries
- Miscellaneous Problems
